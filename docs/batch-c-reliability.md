## 实现边界

- 这是**单进程、多线程**保证。多个 Django worker/多个服务器仍需数据库事务、共享版本和任务队列；内存锁不能解决跨进程问题。
- 正在执行的同步模型请求不能保证立刻终止或停止计费；取消立即禁止后续受保护的状态提交。后台在请求返回并到达取消检查时退出。
- 取消上下文覆盖当前 LangChain 工具/检查点线程池，已有真实 LangGraph 离线测试。以后新增自行创建的线程必须显式传递上下文，并将共享状态写入接入 `writing`/受保护容器。
- 验证仅针对当前代码和**本次默认参数**。调整滑块后的参数空间未自动穷举，动画窗已说明这个边界。
- 候选保存在 `step_drafts`，当前可用版本仍在 `step_cache`；读取会话返回两者。界面继续显示当前可用版本与本次失败原因，本轮未新增历史版本浏览器。
- 旧导入文件和历史缓存继续可读；不把它们追认为通过新协议验证。新生成结果统一走严格的 `accept_step`。
- 进程重启后恢复当前可用版本与候选记录；LangGraph 的内存暂停点仍不会跨进程恢复。
- 未调用真实外部模型，未评估真实题目生成成功率；本轮未重跑批次 B 的浏览器几何样例或进行截图。
