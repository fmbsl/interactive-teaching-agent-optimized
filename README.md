# Manim Agent：数学与物理可视化教学助手

Manim Agent 是一个本地运行的教学可视化工具。输入一句自然语言，它会拆解知识点、生成讲解、编写并播放 `manim-web` 动画，同时提供知识图谱、参数调节、动画验证、历史记录和导出功能。

> 当前版本主要面向 Windows 个人使用。便携版只监听本机 `127.0.0.1`，不需要安装 Node.js、Python、Nginx，也不需要开放端口。

## 直接下载

- [下载 Windows x64 便携版 ZIP](https://github.com/fmbsl/interactive-teaching-agent-optimized/releases/latest/download/ManimAgent-Windows-x64.zip)
- [查看全部版本](https://github.com/fmbsl/interactive-teaching-agent-optimized/releases)

## 主要功能

- 用中文对话生成数学、物理和几何教学动画。
- 自动把主题拆成连续知识点，并生成学习路径图。
- 支持二维场景、三维场景、公式、坐标轴、曲线、箭头和交互参数。
- 动画生成后在浏览器内执行检查，发现错误时自动修复或展示可运行的简化画面。
- 三维布局检查可以单独跳过，三维失败时可要求 Agent 降级成二维表达。
- 支持播放、暂停、单步、重播、截图和录屏。
- 保存会话、动画代码、讲解内容、知识点和执行记录。
- 支持会话切换、重命名、删除、JSON 导入导出和 Markdown 笔记导出。
- 支持多个 OpenAI 兼容接口、备用模型和独立视觉辅助模型。
- 支持深色/浅色主题、自定义样式、学习深度和验证项目设置。

## 一、Windows 便携版使用方法

### 1. 下载并解压

下载 `ManimAgent-Windows-x64.zip`，然后**完整解压**到一个普通文件夹，例如：

```text
D:\ManimAgent\
```

不要直接在压缩包预览窗口里运行，也不要只复制 `ManimAgent.exe`。程序运行需要旁边的 `_internal` 文件夹。

解压后的主要文件：

```text
ManimAgent-Windows-x64\
├─ ManimAgent.exe      # 启动程序
├─ Stop.cmd            # 强制停止程序
├─ README.txt          # 便携版简要说明
├─ _internal\          # 程序运行文件，不要删除
└─ data\               # 首次运行后创建，保存个人数据
```

### 2. 启动

双击：

```text
ManimAgent.exe
```

程序启动后会自动打开默认浏览器，地址通常是：

```text
http://127.0.0.1:8765/
```

如果 `8765` 已被占用，程序会自动选择其他本地端口并打开正确地址。

请保持启动窗口和 `ManimAgent.exe` 进程运行。关闭启动窗口，或双击 `Stop.cmd`，即可停止程序。

### 3. Windows 安全提示

便携版目前没有购买代码签名证书。Windows SmartScreen 首次运行时可能显示“Windows 已保护你的电脑”。确认文件来自本仓库后，可以点击：

```text
更多信息 → 仍要运行
```

### 4. 配置模型接口

打开网页右上角的 **设置 → 模型**，点击“新增接入点”，填写：

| 字段 | 说明 | 示例 |
|---|---|---|
| 名称 | 便于自己区分的名称 | `主模型` |
| 接入 URL | OpenAI 兼容接口的基础地址 | `https://api.openai.com/v1` |
| API Key | 对应服务提供商的密钥 | `sk-...` |
| 模型名 | 服务商实际支持的模型 ID | `gpt-4.1` |
| 备用模型 | 主模型失败时使用，可留空 | 按服务商文档填写 |
| 推理强度 | 模型支持时生效 | `high` |

保存后点击“设为启用”。

如果主模型不支持图片理解，可以在同一页配置“视觉辅助模型”。它只用于可选的动画截图辅助检查，不配置也能使用。

> 接口地址、模型名和 API Key 必须与服务商文档一致。某些服务商虽然兼容 OpenAI 请求格式，但不支持工具调用；这类模型无法正常驱动本项目的 Agent 工作流。

### 5. 第一次生成动画

在左下角输入一句话，例如：

```text
请用简洁稳定的二维动画演示傅里叶级数逼近方波，画面清晰不重叠，失败时自动简化但必须有画面。
```

Agent 可能先询问拆解方式。选择一个选项后，它会依次生成：

1. 知识点列表；
2. 知识分解图；
3. 当前步骤讲解；
4. 动画代码；
5. 浏览器执行与验证结果。

生成过程中不要频繁刷新页面。动画生成完成后，可以使用舞台下方的播放、暂停、下一段、重播、截图和录屏按钮。

## 二、怎样提问更容易得到稳定画面

最简单的通用句式：

```text
请用简洁稳定的二维动画演示【知识点】，画面清晰不重叠，失败时自动简化但必须有画面。
```

示例：

```text
请用简洁稳定的二维动画演示梯度下降，画面清晰不重叠，失败时自动简化但必须有画面。
```

```text
请演示磁通量 Φ=B·S·cosθ，优先使用简化3D；如果3D失败就自动改成二维侧视图，并保证始终有画面。
```

稳定性建议：

- 一次聚焦一个知识点。
- 优先二维；确实需要空间关系时再使用三维。
- 避免只说“做得复杂、高端、炫酷”，这会增加对象数量和动画失败概率。
- 复杂主题建议拆成多个步骤，每一步只表现一个变化。
- 修改已有动画时直接说明要保留什么、删除什么。

常用修正语句：

```text
请简化当前动画，每次最多让三个对象运动，标题、图形和公式分区摆放，不要重叠。
```

```text
不要继续修复复杂3D，直接改成二维投影，优先保证能播放。
```

```text
保留核心公式，删除次要文字，让所有内容自动缩放到16:9画面以内。
```

## 三、界面说明

### 对话区

- **会话**：查看和切换历史会话。
- **新建**：创建空会话；首次提问后会自动用问题命名。
- **附件**：上传 PDF 或文本资料，Agent 可以按需读取。
- **学习深度**：控制讲解风格和拆解粒度。
- 会话右键菜单支持导出 JSON、导出 Markdown、导入和删除。

### 动画舞台

- 展示当前知识点的动画。
- 支持上一步、下一步、播放、暂停、逐段、重置、截图和录屏。
- 参数滑块可以实时调整模型生成的变量。
- 新建或切换会话时会清理旧 Canvas，不会残留上一个三维画面。

### 讲解区

- 展示 Markdown 文本和 KaTeX 数学公式。
- 自动修正常见的 `$$...$$` 多行公式格式。
- 个别无法解析的公式会保留源码，但不会把整段正文显示成红色。
- Agent 生成测验时，可以在此选择答案或跳过。

### 知识分解图

- 展示主题、前置关系和学习顺序。
- 支持缩放、拖动、节点编辑和学习状态标记。

## 四、验证设置

打开 **设置 → 验证** 可以选择动画生成后保留哪些检查。

主要检查包括：

- 脚本是否能执行；
- 场景是否成功创建；
- 公式是否完成渲染；
- 是否出现无效数值；
- 对象尺寸是否能够测量；
- 最终画面是否重叠或越界；
- 动画过程中是否出现短暂重叠或越界；
- 可选的视觉截图辅助检查。

推荐个人使用配置：

- 保留“脚本执行”和基础对象检查；
- 二维动画保留最终布局检查；
- 如果更看重速度，可以关闭动画过程采样；
- 三维动画建议开启“跳过3D布局检查”，因为透视投影容易产生误报；
- 视觉辅助检查需要额外的视觉模型接口，会增加等待时间和接口费用。

关闭某项验证只会减少自动检查，不会修复生成代码本身。遇到播放错误时，优先让 Agent 重新生成简化版本。

## 五、历史记录和数据位置

便携版的全部可写数据都保存在程序旁边的：

```text
data\
```

常用文件：

```text
data\
├─ sessions\
│  ├─ <会话ID>.state.json   # 会话状态、课程、动画和讲解
│  └─ <会话ID>.jsonl        # 对话与工具执行记录
├─ uploads\                 # 上传的资料
├─ llm_endpoints.json       # 模型接口配置
├─ app_settings.json        # 应用设置
└─ user_prefs.json          # 用户偏好
```

注意：

- 历史列表主要依赖 `<会话ID>.state.json`。
- 单独复制 `.jsonl` 不会生成完整历史会话。
- 不建议手工编辑会话文件，优先使用界面的 JSON 导入和导出功能。
- 升级版本时先关闭程序，再把旧版本的整个 `data` 文件夹复制到新版本旁边。
- 迁移到另一台电脑时复制整个解压目录，或者至少复制完整的 `data` 文件夹。
- API Key 保存在本机 `data/llm_endpoints.json` 中。界面会掩码显示，但磁盘文件不是加密保险箱，请只在自己的电脑上保存。

## 六、常见问题

### 双击后网页没有打开

1. 等待 10～20 秒，首次启动可能较慢。
2. 手动访问 `http://127.0.0.1:8765/`。
3. 查看 `data/ManimAgent-error.log` 是否存在。
4. 检查安全软件是否隔离了 `ManimAgent.exe`。
5. 运行 `Stop.cmd` 后重新启动。

### 模型一直没有响应

- 检查接入 URL、API Key 和模型名。
- 确认账户额度和网络连接正常。
- 确认模型支持 OpenAI 兼容的工具调用。
- 在设置中换用另一个接入点或备用模型。

### 动画一直卡在生成阶段

- 等待当前验证和自动修复结束。
- 点击停止后重新发送更简单的要求。
- 关闭耗时的动画过程采样或视觉辅助检查。
- 对三维内容开启“跳过3D布局检查”。
- 明确要求“失败时降级为二维并优先展示可运行画面”。

### 动画画面重叠或超出画幅

可以追问：

```text
请减少同时出现的对象，按标题、主图、公式三个区域重新布局，并让全部内容自动缩放到画面内。
```

### 公式或讲解显示异常

当前版本会自动规范化显示公式的 Markdown 分隔符。若仍出现公式源码，说明模型生成了 KaTeX 不支持的命令，可以要求：

```text
请把讲解公式改写成标准KaTeX语法，使用简单的aligned、frac、sum和cases，不使用自定义宏。
```

### 历史记录没有出现

- 确认使用的是当前 EXE 旁边的 `data/sessions`。
- 关闭并重启程序，让后端重新扫描状态文件。
- 使用界面的“导入 JSON”功能，不要只把普通 JSON 改名后粘贴。
- 每个完整会话至少需要 `<会话ID>.state.json`。

### 可以让其他电脑访问吗

便携版只监听 `127.0.0.1`，设计目标是本机个人使用。它不是多人服务器版本，也不需要开放防火墙端口。

## 七、源码开发

### 环境要求

- Windows、macOS 或 Linux；便携版打包目前针对 Windows x64。
- Node.js 20 或更高版本。
- Python 3.11 或更高版本。
- 一个支持工具调用的 OpenAI 兼容模型接口。

### 安装前端依赖

```bash
npm ci
```

### 安装后端依赖

Windows PowerShell：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
Copy-Item backend\.env.example backend\.env
```

根据需要编辑 `backend/.env`，也可以启动后直接在网页设置中配置模型。

### 启动开发环境

终端一：

```powershell
cd backend
..\.venv\Scripts\python.exe manage.py runserver 127.0.0.1:8000
```

终端二：

```powershell
npm run dev
```

浏览器访问：

```text
http://127.0.0.1:5173/
```

Vite 会把 `/api` 请求代理到 `127.0.0.1:8000`。

### 构建前端

```powershell
npm run build
```

构建结果位于 `dist/`。

### 构建 Windows 便携版

```powershell
powershell -ExecutionPolicy Bypass -File portable\build-portable.ps1
```

首次执行会安装打包依赖，耗时较长。结果位于：

```text
release\ManimAgent\
release\ManimAgent-Windows-x64.zip
```

如果 `.portable-venv` 已准备好，可以跳过重复安装：

```powershell
powershell -ExecutionPolicy Bypass -File portable\build-portable.ps1 -SkipInstall
```

### 测试

```powershell
npm run type-check
npm run test:verification
npm run test:reliability
.\.portable-venv\Scripts\python.exe -m pytest backend\tests -q
```

## 八、项目结构

```text
├─ src\                  # React 前端、动画舞台、验证器和知识图谱
├─ backend\              # Django API、LangGraph Agent、会话持久化
├─ portable\             # Windows 便携版启动器和打包配置
├─ tests\                # 前端可靠性与验证测试
├─ tools\                # 示例和开发工具
├─ LICENSE               # MIT 开源协议
├─ dist\                 # 前端构建产物（生成）
└─ release\              # EXE 与 ZIP（生成）
```

核心流程：

```text
用户问题
  → 主 Agent 拆解主题
  → 步骤 Agent 生成讲解与动画代码
  → 浏览器执行和验证
  → 自动修复或简化展示
  → 保存到本地会话历史
```
