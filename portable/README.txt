Manim Agent Windows 便携版
==========================

1. 双击 ManimAgent.exe。
2. 程序会自动打开默认浏览器；请保持启动窗口开启。
3. 首次使用请在网页右上角“设置”中填写模型接口、API Key 和模型名称。
4. 关闭启动窗口即可停止程序；也可以双击“停止ManimAgent.cmd”。

使用时不需要安装 Node.js、Python、Nginx，也不需要配置或开放端口。
程序只监听本机 127.0.0.1，其他电脑无法通过网络访问。

会话、上传文件及模型配置保存在本目录的 data 文件夹内。
其中 data/sessions 保存对话和生成记录；重新打包或升级程序不会覆盖 data。
复制到其他电脑时请复制整个文件夹，不要只复制 ManimAgent.exe。
